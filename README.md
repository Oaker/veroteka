# Веротека (Verateka)

Публичная энциклопедия религий, конфессий, сект и эзотерических учений.
Нейтральные статьи + слой «Позиция редактора» (Doctor Che).

**Сайт:** https://oaker.github.io/veroteka/

## Текущее состояние (2026-10-25)

- **398 статей** в 9 разделах (все разделы ≥10)
- Сквозная ось классификации: **двайта · адвайта · пустотные** (бейджи + страница «Ось»)
- Блок **«Для профанов»** на каждой статье (110+ ручных объяснений + автогенерация)
- Иллюстрации в ключевых статьях (8, генерация Seedream)
- Поиск (клиентский JSON-индекс), дерево разделов, алфавитный указатель, теги
- Автолинки: упоминания статей в «См. также» кликабельны
- Комментарии под статьями: Giscus (планируется)

## Структура

| Путь | Что это |
|---|---|
| content/ru | Статьи на русском (Markdown, источник истины) |
| content/en | Английские версии (план) |
| site/ | Сгенерированный HTML (создаётся CI, не коммитится) |
| build/ | Скрипт сборки (build.py) + пояснения (plain_texts.py) |
| assets/ | Иллюстрации |
| docs/ | Спецификация, иерархия, рабочие документы |

## Сборка

```bash
python build/build.py
```

Создаёт `site/` из `content/` + `assets/`. CI (GitHub Actions) запускает сборку при каждом пуше и деплоит на Pages.
