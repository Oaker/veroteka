# Веротека (Verateka)

Публичная энциклопедия религий, конфессий, сект и эзотерических учений.
Нейтральные статьи + слой «Позиция редактора» (Doctor Che).

- Спецификация: [spec.md](spec.md) — источник истины по требованиям
- Сайт после публикации: verateka.github.io

## Структура репозитория

| Путь | Что это |
|---|---|
| content/ru | Статьи на русском (Markdown, источник истины) |
| content/en | Английские версии |
| site/ | Сгенерированный HTML — то, что отдаётся на GitHub Pages |
| build/ | Скрипт сборки Markdown -> HTML + поисковый индекс |
| assets/ | Иллюстрации и статика |
| docs/ | Рабочие документы (черновики, планы) |

## Сборка

Скрипт в build/ (в разработке): перегенерирует site/ из content/.
