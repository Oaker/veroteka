# Энциклопедия — спецификация (черновик, 2026-10-24, опрос продолжается)

## Назначение
Публичный сайт, хостинг: GitHub Pages.

## Тема и охват
Религии, конфессии (номинации), секты и эзотерические учения. Максимальный охват:
- мировые религии (христианство, ислам, буддизм, иудаизм, индуизм и др.)
- национальные и региональные традиции (даосизм, синтоизм, зороастризм, афро-культы и др.)
- новые религиозные движения и секты XX-XXI вв., с разбором практик вербовки и рисков
- эзотерика, оккультизм, мистицизм

## Структура
Гибридная: дерево разделов + алфавитный указатель + теги.

## Контент
- Статьи пишутся с нуля агентом, нейтральным энциклопедическим стилем.
- Отдельный слой «Позиция редактора»: уточнения и правки автора (Sergey Che), визуально отделены от основного текста.

## Языки
Русский + английский (двуязычные статьи).

## Хранение и публикация
- Markdown-файлы в git-репозитории (рабочая копия на диске X:).
- Публикация: GitHub Pages (статический сайт, отдаётся напрямую без сборки).
- Генератор: НЕТ движка — сайт пишется вручную на HTML+CSS+JavaScript (решение автора 2026-10-24); поиск — клиентский индекс JSON, поддерживается агентом.

## Стиль и ограничения
- Тон: максимально простой, для широкой публики; юмор, шутки и парадоксы приветствуются (границы юмора уточняются).
- [x9] Целевая аудитория/тон: максимально просто + шутки/юмор/парадоксы
- [x10] Границы юмора: мягкая ирония везде, без сарказма и насмешек над верующими
- [x11] Рискованные темы (секты, вербовка, вред, скандалы): журналистски-критично — открыто называть манипуляции манипуляциями, разбирать техники давления
- [x12] Юридическая осторожность: умеренная — факты всегда; жёсткие формулировки допустимы при надёжных источниках
- [x13] Формат статей: короткие справки с возможностью уйти в детализацию (слоистая глубина: базовая статья + развёрнутые подразделы по ссылкам)
- [x14] Название: «Веротека» (Verateka) — финальный выбор автора 2026-10-24; использовать для шапки сайта, имени репозитория и домена
- [x15] Домен: свой домен позже; пока бесплатный verateka.github.io (репозиторий verateka)
- [x16] Лицензия контента: CC BY 4.0 — с указанием авторства можно всё, включая коммерческое использование (автор: Sergey Che / Веротека)
- [x17] Дизайн: максимально просто, без излишеств (чистый минимализм; тема по умолчанию — уточняется)
- [x18] Навигация: полный набор — поиск + дерево разделов + алфавитный указатель + теги
- [x19] Каркас статьи: стандартный + уровень детализации — заголовок → краткое определение → основная часть → «Источники» → «См. также» → блок «Позиция редактора» (если есть); поле уровня: обзор / подробно / максимум (откат с «свободного» 2026-10-24)
- [x20] Публикация: когда автор скажет «публикуй», без формальных критериев готовности
- [x21] Язык сайта по умолчанию: русский, переключатель на английский в шапке
- [x22] Слой «Позиция редактора»: публикуется от имени аватара «Doctor Che» (персона автора, Sergey Che)
- [x23] «Каширский шиваизм»: реальное новое религиозное движение; в энциклопедии описывается как объект наряду с другими; автор (Doctor Che/Sergey Che) — его приверженец. Размещение (уточнения 2026-10-24, финал): Дхармические → Индуизм → Шиваизм → Каширский шиваизм (отдельный узел уровня живых линий; из кашмирского кластера вынесен по решению автора). Рядом — отдельный узел АДВАЙТА-ДЖАГЛИНГ (недуальное жонглирование) — фирменная практика традиции
- [x24] Роль автора: выступает как религиовед; каширский шиваизм относится с уважением ко всем другим религиям; личная точка зрения автора НИГДЕ не продвигается (слой редактора — религиоведческий комментарий, не проповедь); отдельный disclosure о приверженности не требуется
- [x25] Стартовый контент: рабочий минимум — дерево разделов + 20-30 статей, покрывающих базу мировых религий
- [x26] Обратная связь: комментарии под статьями через Giscus (GitHub Discussions); модерация на авторе
- [x27] Порядок двуязычности: сначала русская версия статьи, английский перевод подтягивается позже
- [x28] GitHub: аккаунт есть; репозиторий создаёт и заливает агент (настроить доступ к моменту публикации)
- [x29] Генерация: Markdown = источник истины; HTML генерируется автоматически при каждом коммите собственным скриптом сборки (сторонние движки не используются)
- [x31] Источники: лёгкий режим — ссылки по мере необходимости; в спорных/критических местах — обязательны; блок «Источники» в каркасе статьи ставится только когда есть что указать
- [x32] Современная политика: не трогаем вообще — только вероучение, история, практики
- [x33] Иллюстрации: по мере необходимости — карты, схемы, фото там, где реально помогают; приоритет — открытые лицензии; если открытого контента нет — генерируем сами (по возможности)
- [x34] Аналитика: лёгкая приватная, без cookie (кандидаты: GoatCounter/Umami); без трекеров вроде GA/Метрики
- [x35] Тема по умолчанию: светлая, переключатель на тёмную в шапке
- Тема чувствительная: нейтральный тон, факты и источники; оценочные суждения — только в слое редактора.
- Дисклеймеры там, где уместно (здоровье, право, безопасность).
